A program that writes one line about a small good thing that happened today: "At 6:04 the night-shift nurse's note was under my locker door — 'Your plant survived' — and below it, in smaller writing, 'So did you. Water it.'" A note left for the narrator; the second line reframes the first, and the plant is still alive.

## Run it

```sh
python3 main.py
```

This writes the line to `/output/entry.txt` (UTF-8, no trailing newline, 145 characters, one line). Deterministic, offline, standard library only.
